# Online Store SQL Analysis

A simple SQL data analysis project for an online store using SQLite.

## Project Overview

This project analyzes online store sales data using SQL queries. It includes product information, sales transactions, and several analyses to understand sales performance and revenue.

## Database Tables

- products
- sales

## SQL Analysis

The project includes:

1. Total units sold for each product
2. Total revenue for each product
3. Total revenue by category
4. Best-selling product
5. Average product price by category
6. Number of sales transactions for each product
7. Most expensive product
8. Cheapest product
9. Total store revenue
10. Product with the highest revenue

## Key Results

- Best-selling product: Headphones — 8 units
- Highest revenue product: Phone — 11,000
- Total store revenue: 27,300
- Highest revenue category: Electronics — 23,900
